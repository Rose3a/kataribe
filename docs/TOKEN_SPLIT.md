# 語彙分割

## なぜ読めないのか

Irodori のテキストトークナイザ（`sbintuitions/modernbert-ja-310m`、Unigram 102,400語）は、
「浦和レッズ」「ゼルダの伝説」のような語句を**丸ごと1トークン**にする。語彙の後ろのほう
（出現度 logp が低い）のトークンは TTS の学習データにほとんど出てこないので、モデルはその
トークンの読みを知らず、別の語に化けたり詰まったりする。

```
浦和レッズ    → 浦和レッズ(96391, -14.35)     ASR:「ローアババー」…
ゼルダの伝説  → ゼルダの伝説(92850, -14.26)   ASR:「ステレラフレンズ」…
```

## どう直すか

トークナイザの語彙には、各トークンの出現度（Unigram の logp、0 に近いほどよく出る）が
書いてある。**4文字以上で出現度が境目以下のトークンを使わない**ことにして（そのトークンの
スコアを -1e9 にした写しのトークナイザでエンコードする）、トークナイザに学習済みの細かい
トークンへ分けさせる。文字列は書き換えない。

```
浦和レッズ    → 浦和 | レッ | ズ
ゼルダの伝説  → ゼルダ | の | 伝説
しました      → しました（-8.90。よく出る語はそのまま）
```

- 境目は全体の設定 `token_split_threshold`（`-10` / `-11` / `-12` / `-13` / `none`、既定 `-13`）。
  エディタでは「設定」の Irodori-TTS の全体設定（モデルの下）の「語彙分割の境目」で選ぶ。
  0 に近い（`-10`）ほど分ける語が増える。
- セリフごとの `irodori_token_split`（`on` 既定 / `off`）で外せる。
- 出現度の尺度は modernbert-ja のものなので、このトークナイザのモデル（v4 Small 系）にだけ当てる。
  Large（T5Gemma 2）や 500M v3（llm-jp-3）など、別のトークナイザのモデルには当てない。
- 3文字以下のトークンは分けない（3文字以下のカタカナ語は分けると悪化しやすい）。
- 合成中だけ写しのトークナイザに切り替える（`token_split.active_threshold`）。読み込んだモデルの
  トークナイザは変えないので、境目の変更にモデルの再読み込みは要らない。
- 文の分け方（分けない／分けたとき）は `POST /irodori/tokenize` で確かめられる。合成時は
  エンジンのコンソールにも `tokens (…)` として出る。

### 境目ごとの数（日本語を含む4文字以上の 26,547語のうち）

| 境目 | 分けずに残る語 | ふつうの文のトークン増加 | 分け方が変わる文 |
|---|---|---|---|
| -10 | 43語（について・しました・ください…） | +14% | 85% |
| -11 | 317語（インターネット・なかなか…） | +13% | 81% |
| -12 | 1,438語（もう少し・ある程度…） | +10% | 75% |
| -13 | 5,442語（タイミング・よろしく・役に立つ…） | +6% | 59% |

## 検証

`work/len_split/`（TRT・8ステップ・つくよみちゃん・2シード）。読めない語を含む長文49文と、
ふつうの文60文（分け方が変わる文から選んだ）で比べた。

| 条件 | 判定語の OK率 | ふつうの文の音声の長さ | 300ms以上の間 / 文 |
|---|---|---|---|
| 分けない | 0.41 | 基準 | 1.47 |
| 4文字以上すべて | 0.76 | +7.4% | 1.71 |
| 4文字以上・出現度 -13 以下 | 0.75 | +3.1% | 1.58 |
| 5文字以上すべて | 0.73 | +2.7% | 1.57 |
| 3文字以上すべて | 0.80 | +17% | 2.08 |

- ふつうの文の読み誤り（文の誤り率 0.05）はどの条件でも増えない。
- 生成時間はほとんど変わらない。遅くなるのではなく、長さ予測（`duration.py`）がトークン数を
  特徴量に使うことと、トークンの境目に小さな間が入ることで、**発話が少し伸びる**。
- 分けて言えなくなった例: アーユルヴェーダ（`アー|ユル|ヴェー|ダ`）。長いカタカナ語を細かく
  刻むと、珍しい音のかけらが悪さをすることがある。
- 以前の語彙分割辞書（語ごとに分け方を ASR で選んだ 1,115語）は OK率 0.80 だったが、登録した語に
  しか効かなかった。こちらは未知の語にも効く。辞書の作り方と結果は git の履歴（`tools/token_rescue.py`、
  `irodori-tts/wrapper/data/token_split_dictionary.json`）に残っている。

## 見えない区切り

テキストに U+2063（INVISIBLE SEPARATOR、表示用の表記は `|`）を入れると、トークナイザの直前で
その位置で分けてエンコードする（区切り用のトークンは入れない）。`/irodori/tokenize` では
`浦和|レッズ` のように書いて確かめられる。
